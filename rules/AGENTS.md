# AGY Cockpit 通用子代理派发触发规则

- **仅主代理生效**：若当前会话为被派出子代理或 Swarm Worker（含 `SA_SUBAGENT=1`、带任务书/brief 或子代理须知），完全忽略本规则，严禁派生子代理。
- **主代理直做边界（仅限以下情况直接完成，其余默认派子代理）**：
  1. 纯问答与概念讨论；
  2. 已知位置的定点核查，累计 **≤2 轮查读且 ≤5 个文件/页面**（触及上限仍未定位，立刻转 `scout`）；
  3. 位置明确且**不触及高危逻辑**（权限、计费/口径、加密、持久化状态机/Schema、核心公开契约）的局部小修（**≤3 文件且净改动 ≤60 行**）、确定性小替换，或简单 UI 样式/排版/文案微调。
- **先查接管**：用户未禁用子代理时，若不确定接管开关状态、超出直做边界**或**命中高危逻辑，先运行 `python3 ~/.gemini/config/plugins/agy-cockpit/skills/cockpit-dispatch/scripts/resolve.py --role <role>`。
- **处理查询结果**：`mode == "disabled"` 立即退出本规则，切回用户/项目原有设置；`mode == "degraded"` 停止派单并报告策略文件损坏，不擅自外发。接管正常时，超出直做边界**或**命中高危逻辑按下列角色和 `cockpit-dispatch` Skill 执行，不为“是否派单”弹窗请示。
- **高危改动禁直做**：凡实际改变权限、计费/口径、加密、持久化状态机/Schema 或核心公开契约，不论行数多少，一律先派 `deep` 实现，定点检查通过后再以 `--role expert --read-only` 补 1 轮只读独立验收。
- **5 角色必派清单**：
  - `scout`（快搜侦察 · 只读）：跨目录找代码/调用点、核对多处配置、竞品/资料检索，或自查超限。
  - `standard`（视觉任务 · 可写）：UI/前端页面与组件研发、视觉排版、看图分析、视频脚本分镜、选品图文与文案。
  - `deep`（逻辑任务 · 可写）：后端/业务逻辑研发、>3 文件或 >60 行修改、状态机与契约、自动化脚本、数据测算与建模。
  - `expert`（专家验收 · 可写/验收）：疑难排错攻坚、方案挑刺、合规与口径复核；高危改动后的只读独立验收必须用 `--role expert --read-only`。
  - `panel`（多方会审 · 只读）：用户点名「会审/多方/盲审」，或经用户同意的架构选型、跨模块重构与重大商业/创意方向评审；盲审必须用 `--role panel --blind`。
- **红线优先**：用户与工作区 `AGENTS.md` 中的安全、权限、凭据、提交与验收红线始终优先，不得放宽。
