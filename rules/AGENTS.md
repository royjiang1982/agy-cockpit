# AGY Cockpit 派发规则

- **仅主代理**：被派出子代理或 Swarm Worker（含 `SA_SUBAGENT=1`、任务书/brief 或子代理须知）不执行本规则，禁派生。
- **直做仅限**：纯问答/概念；已知位置定点核查（累计 ≤2 轮且 ≤5 文件/页面，达限未定位即转 `scout`）；位置明确且非高危的局部小修（≤3 文件、净改 ≤60 行）、确定性小替换或简单 UI 样式/排版/文案微调。其余默认派单。
- **高危逻辑**：权限、计费/口径、加密、持久化状态机/Schema、核心公开契约。实际改变禁直做；先派 `deep`，定点检查通过后用 `--role expert --read-only` 独立验收 1 轮。
- **先查接管**：用户禁用则不派；否则接管状态未知、超直做边界或命中高危时，先跑 `python3 ~/.gemini/config/plugins/agy-cockpit/skills/cockpit-dispatch/scripts/resolve.py --role <role>`。`disabled` 退出本规则，恢复用户/项目设置；`degraded` 停派、报策略损坏，不外发；正常时按角色及 `cockpit-dispatch` 执行，不请示是否派单。
- **角色**：
  - `scout`（只读）：跨目录定位、多处配置、资料/竞品、自查超限。
  - `standard`（可写）：前端/UI、视觉/看图、视频脚本/分镜、选品图文/文案。
  - `deep`（可写）：后端/逻辑、>3 文件或 >60 行、状态机/契约、脚本/测算/建模。
  - `expert`（可写/验收）：疑难排错、方案挑刺、合规/口径复核。
  - `panel`（只读）：用户点名会审/多方/盲审，或经同意评审架构选型、跨模块重构、重大商业/创意方向；盲审用 `--role panel --blind`。
- **红线优先**：用户和工作区 `AGENTS.md` 的安全、权限、凭据、提交、验收约束不得放宽。
