# AGY Cockpit 通用子代理派发触发规则

- **仅主代理生效**：若当前会话为被派出子代理或 Swarm Worker（含 `SA_SUBAGENT=1`、带任务书/brief 或子代理须知），完全忽略本规则，严禁派生子代理。
- **主代理直做边界（仅限以下情况直接完成，其余默认派子代理）**：
  1. 纯问答与概念讨论；
  2. 已知位置的定点核查，累计 **≤2 轮查读且 ≤5 个文件/页面**（触及上限仍未定位，立刻转 `scout`）；
  3. 位置明确且**不触及高危逻辑**（权限、计费/口径、加密、持久化状态机/Schema、核心公开契约）的局部小修（**≤3 文件且净改动 ≤60 行**）、确定性小替换，或简单 UI 样式/排版/文案微调。
- **5 角色必派清单**（超出直做边界、命中高危逻辑，且用户未明确禁用子代理时，**先运行** `python3 ~/.gemini/config/plugins/agy-cockpit/skills/cockpit-dispatch/scripts/resolve.py --role <role>`）：
  - `scout`（快搜侦察 · 只读）：跨目录找代码/调用点、核对多处配置、竞品/资料检索，或自查超限。
  - `standard`（视觉任务 · 可写）：UI/前端页面与组件研发、视觉排版、看图分析、视频脚本分镜、选品图文与文案。
  - `deep`（逻辑任务 · 可写）：后端/业务逻辑研发、>3 文件或 >60 行修改、状态机与契约、自动化脚本、数据测算与建模。
  - `expert`（专家验收 · 可写/验收）：疑难排错攻坚、方案挑刺、合规与口径复核，以及**高危改动完成后的只读独立验收**。
  - `panel`（多方会审 · 只读）：用户点名「会审/多方/盲审」，或经用户同意的架构选型、跨模块重构与重大商业/创意方向评审。
- **接管与回退**：当 `resolve.py` 返回 `mode != "disabled"`（Cockpit 已开启「接管子代理编排」）时，立即按 `cockpit-dispatch` Skill 派单执行，不为“是否派单”弹窗请示；当 `mode == "disabled"` 时切回用户或项目原有设置。
- **红线优先**：用户与工作区 `AGENTS.md` 中的安全、权限、凭据、提交与验收红线始终优先，不得放宽。
